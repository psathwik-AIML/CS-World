Gradients

for using background color transitions we use this

4 types:

  • linear gradient
  • radial gradient
  • repeating linear gradient
  • repeating radial gradient

linear gradient

colors in horizontal application

radial gradient

colors in circular application

repeat linear gradient

same as linear but colors will repeat if we give width for colors

repeat radial gradient

same as radial but colors will repeat if we give width for colors

text gradient

gradient for text
