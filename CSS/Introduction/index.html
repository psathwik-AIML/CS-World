CSS

CSS - cascading style sheet

css is used to style webpages

In 3 ways we can apply css for web pages

  1. Inline
  2. Internal
  3. External

Inline css

inline css is applied at tag level for individual tags


example:

India is most populated country in the world

Internal css

internal css is applied in the head tag

better than inline css

example:

india nation language is hindi

External css

external css is applied in new file with extension .css

better than inline and internal css

example:

india nation language is hindi

by using link tag we link html and css files
