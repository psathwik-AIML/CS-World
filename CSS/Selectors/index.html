Selectors

selectors are used in internal and external css
    to tell that for which tag we should apply css

Types of selectors

  1. Simple Selectors
  2. combinator Selectors
  3. pseudo - element Selectors
  4. Attribute Selectors
  5. pseudo -class Selectors

Simple selector

        syntax:

                tag-name{
                    property:value;
                }

Combinator selectors

combinator selector is used on combination of tags / classes

Types of combinator selectors

  • Child selector (>)
  • Descendent selector (space)
  • Adjacent sibling selector (+)
  • General Sibling selector (-)

Pseudo Elements selector

used to style a specific part of selected elements 
    
        syntax:

Attribute Selector

        used to style an element with specific attribute or attribute value
    
        syntax: 
            selector[attribute name]{
                property:value;
            }
