Prototype and __proto__

  • Every function you create in JavaScript automatically gets an empty object attached to it called prototype.
  • Every object created in JavaScript automatically gets a hidden property called __proto__.
  • The prototype is used to share properties and methods like inheriting from parent to child.
  • This pattern is used to save memory by preventing duplicate code allocations.
  • prototype belongs to the function (the creator).
  • __proto__ belongs to the object instance (the creation).
