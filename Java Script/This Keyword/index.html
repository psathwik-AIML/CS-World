This Keyword

this keyword in java script represents the object maximum

but according to placement it changes which it targets

this outside function and object:
this represents window object (pre-built)
this inside function:
this represents window object (pre-built)
this inside methods(object function):
this represents window object (pre-built)
this inside event handlers:
this represents current element.use normal function not arrow
this inside function with strict mode:
it shows undefined if we use "use strict"
