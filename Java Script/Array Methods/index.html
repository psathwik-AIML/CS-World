Array Methods

methods applied on arrays to make code flexible

map method:
after doing some operation on elements of array it will return new array
filter method:
after doing filter on elements of array it will return new array with true condition only
reduce method:
after doing reduce on elements of array it will return only single
find method:
first element true then returns
some method:
same like find but returns true or false not element
every method:
return true if all elements call back function return true
