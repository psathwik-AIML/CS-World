table is used to arrange data in rows and columns

    table 
    table is a tag 
    th is table headings 
    tr is a table row 
    td is table data 
    border is to add line around table
    border collapse is a attribute for table to combine borders 
    cell padding is a attribute used to give padding inside cell 
    cell spacing is a attribute used to give space b/w cells only works if we remove border collapse 
    align is aattribute used to align elements
